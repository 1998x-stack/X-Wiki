# X-Wiki Schema

X-Wiki 是个人 LLM wiki：`raw/` 是不可变证据，`wiki/` 是编译后的知识层，`index.md`+`log.md` 是入口与变更日志。发布到 GitHub Pages，只有 `wiki/`、`index.md`、`log.md` 与站点资产对外可见。

## 分层

- `raw/voice/YYYY/MM/`：不可变转写稿与录音元数据。
- `raw/references/`：不可变的外部/架构性来源笔记。
- `wiki/concepts/`：可复用的心智模型与想法。
- `wiki/entities/`：人物、组织、作品、地点、具名系统。
- `wiki/projects/`：有产出和下一步行动的活动工作。
- `wiki/decisions/`：持久决策、理由、后果与复查条件。
- `wiki/synthesis/`：连接多个概念的跨来源长文。

## 链接约定

使用仓库根相对、不含文件后缀的 wiki 链接：

```markdown
[[wiki/concepts/example|可读标签]]
[[raw/voice/2025/02/source-id|源录音]]
```

每个编译页面以 `## 来源` 结尾；仅当它确实支撑该页内容时才加来源。

## 编译决策

- 当来源强化、支持、挑战或扩展某页核心思想时，更新既有页。
- 当想法可在多语境复用时才新建概念。
- 仅当追踪某实体能改进检索或关系时才建立实体。
- 仅当至少两个来源或概念互相连接产生新意义时才建立综合篇。
- 除非来源叙事本身就是可复用的项目/决策记录，否则把特定来源的时间线留在 raw 证据里。
- 把矛盾记录在最相关的持久页上，不单独建立矛盾页。
- 当来源只是重复已准确表达的知识时，优先零改动。

## 公共边界

`wiki/` 与 `index.md` 通过 GitHub Pages 发布；`raw/voice/` 仅留本地。

- 在标识细节非必需时，把私人经验提炼为可复用想法。
- 绝不把本地音频路径、凭据、联系方式或私人标识写进公开页。
- 来源链接可指向本地 raw 路径；站点渲染器会把它们转成不可点击的“本地证据”标签。

## 质检

完成后确认：无任何 raw 文件被改；新链接都能解析；未引入重复概念；解读与源主张可分；`index.md` 只暴露真正重要的页面；公开文本不含多余的私密细节。
